# Формат приложения-виджета (API 1)

Приложения живут на **microSD**, не во flash. Причина: у платы 4 МБ flash, и двойной
OTA-слот занимает почти всё. Шрифты и картинки — тоже на SD.

```
/sd/apps/<id>/
    manifest.json     обязателен
    ui.jsonl          слой A: декларативный интерфейс
    main.lua          слой B: логика (пока не реализован)
    icon.bin          опционально, LVGL binary image
```

«Установка» приложения = скопировать папку на карту. Никакой перепрошивки и компиляции.

## manifest.json

```json
{
  "api": 1,
  "id": "weather",
  "name": "Weather",
  "version": "1.0.0",
  "layer": "declarative",
  "entry": "ui.jsonl",
  "capabilities": ["net.http", "time"],
  "poll_sec": 900
}
```

| Поле | Обязательно | Смысл |
|---|---|---|
| `api` | да | Версия контракта. Оболочка **отказывается** грузить незнакомую версию, а не пытается разобрать наполовину. |
| `id` | да | Латиница, уникален. По умолчанию — имя папки. |
| `name` | да | Отображаемое имя. ⚠️ Пока только латиница (см. ниже). |
| `version` | нет | Семвер, для будущих обновлений. |
| `layer` | нет | `declarative` (по умолчанию) или `lua`. |
| `entry` | нет | Точка входа, по умолчанию `ui.jsonl`. |
| `capabilities` | нет | См. таблицу ниже. Не объявил — не получил. |
| `poll_sec` | нет | Период обновления данных. |

⚠️ **Кириллица в `name` пока не отрисуется.** Встроенные шрифты Montserrat в LVGL
содержат только ASCII/Latin-1 и символы, глифов кириллицы там нет. Нужен шрифт,
сгенерированный `lv_font_conv`. Это открытая задача.

## Capabilities

| Значение | Даёт | Поведение без ПК |
|---|---|---|
| `net.http` | HTTP(S)-запросы наружу | работает, нужен только WiFi |
| `time` | локальное время, таймеры, будильники | работает |
| `storage` | чтение/запись в своей папке | работает |
| `host` | данные от ПК-агента | **недоступно**, см. ниже |
| `notify` | RGB-LED и динамик | работает |

### Правило автономности

Устройство обязано быть полезным при спящем или выключенном ПК. Поэтому:

1. Приложение **без** `host` обязано быть полностью функционально без ПК.
2. Приложение **с** `host` при отсутствии агента **не исчезает** из лончера — оно
   помечается как недоступное и показывает последнее полученное значение с отметкой
   давности. Падать и показывать пустоту нельзя.
3. Напоминания и будильники живут **на устройстве** (расписание на SD/в NVS, свой
   планировщик, сигнал через LED и динамик). Держать их на ПК нельзя — умрут вместе с ним.

## Бинды на кнопки

Три кнопки → 7 непустых масок × (короткое/длинное) = 14 действий, плюс двойной клик
и автоповтор при удержании.

Системные комбинации оболочка забирает себе, приложение их **не видит**:

| Комбинация | Действие |
|---|---|
| `B1+B3` коротко | домой / лончер |
| `B1+B2` коротко или автоповтор | яркость по кругу |
| `B1+B2+B3` длинно | аварийный выход из зависшего виджета |

Остальное приложение запрашивает в манифесте (поле `bindings`, ещё не реализовано);
конфликты разрешает оболочка, система всегда выигрывает.

## Слой A — `ui.jsonl`

JSON Lines: одна строка = один объект. Формат в духе openHASP, сознательно —
изобретать свой смысла нет. Интерпретатор ещё не написан; целевой вид:

```jsonl
{"id":0,"obj":"label","x":8,"y":8,"text":"{{current.temperature_2m}} C","font":28}
{"id":1,"obj":"label","x":8,"y":48,"text":"{{daily.temperature_2m_max.0}} / {{daily.temperature_2m_min.0}}"}
{"src":"http","url":"https://api.open-meteo.com/v1/forecast?latitude=55.75&longitude=37.62&current=temperature_2m","every":900}
```

Ключевая идея: **на устройстве не исполняется код приложения**. Есть layout и есть
привязка полей к путям в JSON-ответе. Этим закрывается большинство виджетов —
погода, курсы, любые REST-табло — при минимальном расходе RAM, которой на этой плате
всего ~300 КБ.

## Слой B — Lua

Для виджетов с логикой: напоминания, помидор, игры. Добавляется, **когда слой A
упрётся**, не раньше. Lua выбран за размер (~150–200 КБ flash) — на плате без PSRAM
это единственный реалистичный вариант скриптования.
