# Внешние источники и ассеты

Список того, что проект использует, но не создавал сам — данные и картинки.
Код лицензий/условий смотреть по месту (Open-Meteo — открытые условия;
иконки — см. `assets/icons/README.md`, там же явно отмечено то, что открытой
лицензии не имеет и используется по решению пользователя).

## Данные

- **[Open-Meteo](https://open-meteo.com/)** — погодный API, встроенный
  виджет `weather` (`main/builtin/weather.ui.jsonl`, `api.open-meteo.com`).
  Бесплатный, без ключа, некоммерческое использование. Кредит уже на экране
  виджета текстом («open-meteo, ...» под прогнозом) — этот файл фиксирует
  саму ссылку отдельно от кода, чтобы не потерять её при рефакторинге
  строки на экране.

## Иконки

См. `assets/icons/README.md` — там же и лицензии по каждому набору
(google-weather-icons, Material Symbols), и статус пользовательского
логотипа About device.
